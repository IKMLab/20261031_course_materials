# 20261031 課程材料

這個儲存庫是課堂使用的教學材料，主要介紹常用基本工具套件的使用方式與核心功能。

## 教材內容

- `numpy-基本功能.ipynb`：NumPy 陣列與基本數值運算
- `pandas-基本功能.ipynb`：Pandas 資料處理與分析
- `matplotlib-資料視覺化.ipynb`：Matplotlib 基本資料視覺化
- `scikit-learn-基本功能.ipynb`：scikit-learn 基本機器學習功能
- `exercises.ipynb`：課堂練習

## Notebook 圖片

教學圖片以 Base64 data URI 直接內嵌在 `.ipynb` 的 Markdown 中；已執行的圖表也保存在 notebook 輸出中。單獨下載 notebook、移到其他資料夾，或上傳 Google Colab 時，不需要額外下載 `images/` 資料夾即可閱讀圖片。

在 Colab 選擇「檔案 → 上傳筆記本」並選取 `.ipynb` 即可。若要重新執行讀取 CSV 的程式，仍須上傳所需的 `data/` 資料；這與內嵌圖片的顯示無關。
